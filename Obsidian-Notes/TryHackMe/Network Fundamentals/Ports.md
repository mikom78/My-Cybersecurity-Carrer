Think of an IP address like the **street address** of a big apartment building. The **Ports** are the specific **apartment numbers**.


-There are over 65535 ports, starting from 0 - 65,535 ports.

-The Three categories are ->

| **Range**           | **Name**             | **What they are for**                                       |
| ------------------- | -------------------- | ----------------------------------------------------------- |
| **0 – 1,023**       | **Well-Known Ports** | Reserved for famous services (HTTP, SSH, FTP).              |
| **1,024 – 49,151**  | **Registered Ports** | For specific apps you might install (like a game server).   |
| **49,152 – 65,535** | **Dynamic/Private**  | Temporary ports that your PC uses to talk back to a server. |

-Common Ports ->
- **Port 21**: FTP (File Transfer)
- **Port 22: SSH** (Secure Shell)
- **Port 25:** SMTP (Email)
- **Port 53:** DNS (Domain Name System)
- **Port 80:** HTTP (Hypertext Transfer Protocol - Not secure)
- **Port 443:** HTTPS (HTTP with S-Secure/Encrypted)
- **Port 3389:** RDP (Remote Desktop Protocol)
